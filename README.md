# Cyber-Security
This is a repository for Cyber Security course Batch B082 with Networkworks
Cybersecurity Footprinting with HTTrack
📌 Purpose
Footprinting is the first step in ethical hacking. It helps security professionals gather information about a target system in a safe and controlled way. Using HTTrack, I mirrored a website onto my local machine for offline analysis.
💻 Lab Environment
•	Tool Used: HTTrack Website Copier
•	Host Machine: Intel i7, 16GB RAM, Windows 11
•	Network: Isolated lab environment (no direct interaction with live server)
🛠️ Steps Taken
1.	Installed HTTrack on my PC.
2.	Configured project settings.
3.	Mirrored the website locally.
4.	Analyzed the offline copy structure, directories, and files.
✅ Verification
•	Confirmed that the mirrored site opened offline.
•	Checked directory structure and HTML files.
•	Verified no interaction with the live server during analysis.
⚠️ Issues Faced & Solutions
1.	Slow download speed → Adjusted HTTrack settings to limit connections.
2.	Broken links → Enabled “Get non HTML files” option.
3.	Large site size → Selected specific directories instead of full site.
4.	Duplicate files → Cleaned up using HTTrack filters.
5.	Encoding errors → Changed character set in HTTrack preferences.
📚 What I Learned
•	How HTTrack replicates websites for offline analysis.
•	Importance of footprinting in cybersecurity.
•	Safe reconnaissance practices without touching live servers.
